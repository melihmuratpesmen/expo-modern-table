Every text the table shows — and every accessibility label it announces — comes from the
`translations` prop. Pass only the keys you want to change; the rest fall back to English.

```tsx
<ModernTable
  columns={columns}
  {...table.getTableProps()}
  translations={{ searchPlaceholder: 'Search orders…', empty: 'No orders yet' }}
/>
```

## Turkish

A complete Turkish set is included:

```tsx
import { TR_TRANSLATIONS } from 'expo-modern-table';

<ModernTable /* … */ translations={{ ...TR_TRANSLATIONS, searchPlaceholder: 'Sipariş ara…' }} />;
```

The English defaults are exported as `DEFAULT_TRANSLATIONS`. A pull request with your language
is very welcome.

## Locale-aware data

- **Sorting** compares text with `Intl.Collator` in the device locale; set
  `useTable(data, columns, { locale: 'de' })` to choose one.
- **Search** ignores case and accents in every language and folds the Turkish `İ / I / ı / i`.
- **Summary row** numbers use `Intl.NumberFormat` in the device locale.
- **Number input** in editable cells and range filters accepts both `.` and `,` as the decimal
  separator.
