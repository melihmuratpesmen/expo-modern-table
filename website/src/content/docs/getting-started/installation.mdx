import { Tabs, TabItem, Steps, Aside } from '@astrojs/starlight/components';

<Steps>

1. **Install the package and its peers**

   <Tabs syncKey="pm">
     <TabItem label="Expo">
       ```bash
       npx expo install expo-modern-table @shopify/flash-list react-native-gesture-handler react-native-reanimated react-native-worklets react-native-svg lucide-react-native
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install expo-modern-table @shopify/flash-list react-native-gesture-handler react-native-reanimated react-native-worklets react-native-svg lucide-react-native
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add expo-modern-table @shopify/flash-list react-native-gesture-handler react-native-reanimated react-native-worklets react-native-svg lucide-react-native
       ```
     </TabItem>
     <TabItem label="pnpm">
       ```bash
       pnpm add expo-modern-table @shopify/flash-list react-native-gesture-handler react-native-reanimated react-native-worklets react-native-svg lucide-react-native
       ```
     </TabItem>
   </Tabs>

   `react-native-worklets` is only needed with Reanimated 4. Apps created with
   `create-expo-app` already include Reanimated, Gesture Handler and SVG — `npx expo install`
   picks versions that match your SDK.

2. **Wrap your app in `GestureHandlerRootView`** (once, at the root)

   ```tsx title="App.tsx"
   import { GestureHandlerRootView } from 'react-native-gesture-handler';

   export default function App() {
     return (
       <GestureHandlerRootView style={{ flex: 1 }}>
         {/* your navigation / screens */}
       </GestureHandlerRootView>
     );
   }
   ```

   Expo Router apps can do this in `app/_layout.tsx`.

3. **Bare React Native only: add the Babel plugin**

   Expo's `babel-preset-expo` configures it for you. In a bare app, add the plugin **last**:

   ```js title="babel.config.js"
   module.exports = {
     presets: ['module:@react-native/babel-preset'],
     plugins: [
       // Reanimated 4: 'react-native-worklets/plugin' · Reanimated 3: 'react-native-reanimated/plugin'
       'react-native-worklets/plugin',
     ],
   };
   ```

</Steps>

That's it — continue with the [quick start](/expo-modern-table/getting-started/quick-start/).

## Peer dependencies

| Package | Required | Tested with |
| --- | --- | --- |
| `react`, `react-native` | Yes (`>=18`, `>=0.73`) | React 19.1 · RN 0.81 (Expo SDK 54) |
| `@shopify/flash-list` | Yes — v1 (`>=1.6`) or v2 | 2.x |
| `react-native-gesture-handler` | Yes (`>=2.14`) | 2.28 |
| `react-native-reanimated` | Yes (`>=3.6`) | 4.1 |
| `lucide-react-native` | Yes — default icons, [replaceable](/expo-modern-table/guides/theming/#icons) | 0.556 |
| `react-native-svg` | Yes, through `lucide-react-native` | 15.12 |
| `expo-screen-orientation` | No — only for the [fullscreen button](/expo-modern-table/guides/fullscreen/) | 9.0 |

Everything is compatible with **Expo Go** — no custom native code, no dev build required.

## Web

The table works with [react-native-web](https://necolas.github.io/react-native-web/). In an
Expo app:

```bash
npx expo install react-dom react-native-web @expo/metro-runtime
```

See [Web support](/expo-modern-table/guides/web/) for what differs from native.

## Jest

The package ships ES modules (`lib/module`). If your Jest config doesn't already transform React
Native packages from `node_modules`, add it to `transformIgnorePatterns` — `jest-expo` and the
`react-native` preset need the same for `lucide-react-native`, `react-native-reanimated` and
friends:

```js title="jest.config.js"
module.exports = {
  preset: 'jest-expo',
  transformIgnorePatterns: [
    'node_modules/(?!((jest-)?react-native|@react-native(-community)?)|expo(nent)?|@expo(nent)?/.*|@shopify/flash-list|lucide-react-native|expo-modern-table)',
  ],
};
```

<Aside type="tip">
  Gesture Handler and Reanimated provide Jest setups:
  `react-native-gesture-handler/jestSetup` and `require('react-native-reanimated').setUpTests()`.
</Aside>
