**expo-modern-table** is a data table component for Expo and React Native. It is a finished,
themeable UI — not a headless toolkit — built on
[FlashList](https://shopify.github.io/flash-list/), Reanimated and Gesture Handler, and it runs
on iOS, Android and the web.

You give it rows and column definitions; a `useTable` hook handles search, sorting, filters,
pagination and selection on the device, or just the state when your API does the work.

```tsx
const table = useTable(orders, columns, 20);

return <ModernTable columns={columns} {...table.getTableProps()} />;
```

## When to use it

- You show **real data** on mobile: orders, reports, inventories, leaderboards, transactions,
  admin panels — anything with more than a handful of columns or rows.
- You want a **polished default** that already handles sticky columns, gestures, empty states
  and theming, instead of assembling it from primitives.
- You need the **same table on phones, tablets and the web** (react-native-web).

## When something else fits better

- **A small, static table** in an app that already uses React Native Paper —
  [Paper's `DataTable`](https://oss.callstack.com/react-native-paper/docs/components/DataTable/DataTable)
  has no extra dependencies.
- **A completely custom design**, or table logic shared with a React web app — the headless
  [TanStack Table](https://tanstack.com/table) gives you state and logic and leaves rendering
  (and virtualization, gestures) to you.

See the [comparison](/expo-modern-table/comparison/) for a feature-by-feature look.

## Stability

The package is `0.x`: the API is settling and breaking changes are possible before `1.0`, but
they are called out in the [changelog](https://github.com/melihmuratpesmen/expo-modern-table/blob/main/CHANGELOG.md).
It is used in production at [MyExamy](https://myexamy.com).
